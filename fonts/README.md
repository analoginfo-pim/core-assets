# Brand fonts

| Font | File | Use |
| --- | --- | --- |
| Inter | `Inter-VF.ttf` | Headlines and body text |
| Urbanist | `Urbanist-VF.ttf` | Company name next to the AIC logo |

Both are variable fonts released under the SIL Open Font License 1.1. The
license text ships beside each font (`Inter-OFL.txt`, `Urbanist-OFL.txt`).

Word and PowerPoint use these fonts only when they are installed on the
machine that renders the file. Install both before rendering briefings or
templates.

The official logo is `branding/AIC_logoWhite.webp`, a white mark with "AI"
underlined. `branding/aic-logo-white.png` is a pixel-identical PNG copy of
it for tools that cannot read WebP. Do not create, recolor, or crop logos.
